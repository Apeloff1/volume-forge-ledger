# Masterplan

Second stratum on the volume forge. Target is ten million measured lines. The estimate is not the census.

## Strata

1. Kernel. Clip, era, merkle, pointer cap. Hand written.
2. Organ emit. 64 houses, 36 organs, 48 verbs. Measured at 3,329,408 lines.
3. Masterplan shards. 200 files, 8,500 bindings each. Counted after write.

## Law

- Mass grows at most prior times 1.1 per binding.
- stored_prose is 0.
- Shard tree is regenerated. It is not committed.
- Census overwrites the writer estimate.

## Compile

```bash
python -m volume_forge.masterplan emit10
```

Then count newlines on emit10. Discard the writer estimate.
